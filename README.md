# Simple KPI Tracking Dashboard 📊

## 📌 Project Overview
The **Simple KPI Tracking Dashboard** is an Excel-based data analytics task that transforms raw sales transaction data into meaningful business insights. It uses Excel formulas to summarize sales performance in a clean, one-page dashboard.

## 🎯 Objectives
- Track overall sales revenue.
- Calculate total units sold.
- Calculate Average Order Value (AOV).
- Identify the top-performing product by total sales.
- Automate KPI calculations as new data rows are added.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Excel Tables and Formulas
- Sample Superstore Dataset

## 📈 Key Performance Indicators (KPIs)
1. **Total Revenue** – Sum of all sales.
2. **Units Sold** – Total quantity of products sold.
3. **Average Order Value** – Total revenue divided by the number of unique orders.
4. **Top Product** – Product with the highest combined sales.

## ⚙️ Features
- One-page KPI dashboard.
- Color-coded KPI cards.
- Automatic calculations using Excel formulas.
- Structured raw data for easier analysis.
- Simple and readable presentation of business metrics.

## 📂 Project Structure
- `Simple_KPI_Tracking_Dashboard.xlsx` – Excel workbook containing the raw dataset and KPI dashboard.
- `README.md` – Project documentation.

## 🚀 How to Use
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Navigate to the `Dashboard` worksheet to view the KPIs.
4. Add new order records to the `OrdersData` table in the `Raw_Data` worksheet.
5. Check the dashboard to see the updated KPI values.
